# SHIcons (Shell Icons Prototype)

[![Language](https://img.shields.io/badge/Language-C%23-239120.svg?logo=csharp&logoColor=white)](#overview)
[![Framework](https://img.shields.io/badge/Framework-WPF%20%7C%20.NET%20Framework%204.7.2-512BD4.svg?logo=dotnet&logoColor=white)](#overview)

A proof-of-concept utility written in **August 2019** that explores extracting and rendering system icons indexed within Windows `shell32.dll` via P/Invoke. 

This experiment served as the direct technological foundation for the icon extraction pipeline later deployed in **AppsIndexator** and **FoxDock**.
